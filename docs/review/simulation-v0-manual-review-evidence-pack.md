# Simulation v0 Manual Review Evidence Pack

This evidence pack supports manual visual review of the Simulation v0 route for ER Pod Shift Simulator.

Simulation v0 is an internal synthetic dry-run review surface. It is not a full-shift simulation, optimizer, assignment recommendation workflow, clinical safety score, staffing compliance certification, patient outcome prediction, EHR workflow, or production approval artifact.

## Review Focus

Review route wording, activity profile clarity, 4:1 / 3:1 planning controls, timeline readability, summary cards, occupied-bed proof, artifact hash proof, export workflow, confusing wording, misleading claims, and layout or scrolling issues.

## Limits

Manual visual review remains required. Promotion remains blocked. This pack uses synthetic operational data only and does not include PHI, EHR data, real staff data, real facility identifiers, medication names, diagnosis text, or clinical notes.
