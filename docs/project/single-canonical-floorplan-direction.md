# Single Canonical Floorplan Direction

The product direction for this stage is one canonical ER pod floorplan.

Future 4:1 nurse ratio, 3:1 nurse ratio, ER activity level, patient-load, acuity-pattern, and operational-outcome comparisons must layer scenario inputs on top of that same canonical floorplan. They must not create a multi-floorplan product path.

This geometry repair batch prepares the editor and geometry foundation only. It does not add ratio scenario simulation, ER activity presets, full-shift simulation behavior, optimizer behavior, clinical safety scoring, promotion, or manual visual approval.

Default source fixtures remain source defaults. Corrected, repaired, imported, or locally saved draft copies must not be promoted into defaults without a later explicit promotion-review batch.
