# Codex Global Invariants

These invariants apply to every issue until a later accepted contract changes them.

- The product is an operational simulation tool, not a clinical safety system.
- All simulated work must use abstract rooms, loads, assignments, assumptions, scores, and reports.
- No PHI, real patient identity, EHR integration, diagnosis text, or clinical note workflow is allowed.
- Scoring must be explainable and shared by manual and optimized assignment flows.
- Optimization must not exist before scoring is implemented and verified.
- Simulation randomness must be seeded and reproducible.
- Evidence must be written before an issue is considered complete.
