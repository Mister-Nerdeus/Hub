# Floorplan Editor Reference Style Checklist

The reference-style goal is a clean operational map, not source-document parity.

- Product display name remains `ER Pod Shift Simulator`.
- Edit Geometry mode keeps grid, handles, geometry tools, and neutral room rendering.
- Assignment View mode shows synthetic assignment color overlays.
- Presentation View mode hides grid clutter and reduces debug chrome.
- Assigned rooms use synthetic nurse assignment colors.
- Unassigned occupied rooms are visually distinct.
- Warning rooms have a distinct outline.
- Door access markers render as capsules or ovals.
- Selected doors remain visually obvious.
- Hallway arrows are visible in presentation mode and make no route-truth claim.
- Nurse stations have presentation-specific curved/desk styling.
- Provider/pharmacy area is visually separated.
- EMS/hallway labels remain readable.
- Manual review remains required.
- Promotion remains blocked.
- No PHI, EHR, private source, optimizer, or full-shift simulation behavior is introduced by this styling work.
