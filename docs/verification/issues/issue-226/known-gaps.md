# Known Gaps

- JSON floorplans are approximate operational fixtures, not exact CAD geometry.
- Imported JSON floorplans currently load as editor-local drafts; saved-store persistence for imported plans is not added.
- Developer Proof Mode is local UI state and not production navigation polish.
- Route/walking-truth calculation, nurse assignment workflow, assignment scoring, optimizer behavior, simulation reruns, OCR, DOCX serving, production deployment, and database seeding remain out of scope.
