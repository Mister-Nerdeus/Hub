# Issue 206 Known Gaps

- Metadata is available to future work, but path graph editing does not yet use it.
- Assignment scoring does not yet consume room, overflow, adjacency, entry, hallway, door, station, or zone metadata.
- The layout editor does not yet expose full editing controls for every metadata object.
- Reference validation covers declared metadata references, but no route or path cost calculation uses those references yet.
- The canonical fixture is operational test data only and is not a real site plan.
