# Corrected Plan Review Protocol

This protocol reviews corrected saved-copy floorplans as operational simulation artifacts only.

## Scope

- Review corrected saved-copy JSON generated by the prior source-correction batch.
- Generate rendered visual evidence only from corrected saved-copy JSON.
- Run route/path and simulation-ready export audits against corrected saved copies or reviewed exports.
- Classify every corrected plan as blocked, machine-review complete with manual review required, or ready for a future promotion-review batch.

## Hard Boundaries

- Do not mutate default source fixtures.
- Do not promote corrected saved copies into default fixtures.
- Do not add optimizer behavior or simulation scoring/model behavior.
- Do not store DOCX files, source screenshots, OCR dumps, raw source text, source filenames, private paths, embedded documents, source binaries, or base64 source payloads.
- Do not introduce PHI, EHR content, real patient or staff identifiers, diagnosis text, medication details, clinical notes, or real hospital identifiers.
- Do not claim exact CAD parity or exact DOCX parity.
- Do not claim completed human/manual visual approval.

## Review Steps

1. Preflight the source-correction manifest and corrected saved-copy artifacts.
2. Render deterministic PNG evidence from each corrected saved-copy JSON file.
3. Validate render metadata, hashes, dimensions, object counts, and machine visual sanity checks.
4. Audit route/path readiness against the corrected saved copy or reviewed export.
5. Validate simulation-ready export status.
6. Validate private-source and non-PHI boundaries.
7. Write a per-plan review artifact and batch manifest entry.
8. Produce a GO / NO-GO decision without promotion.

## Classification Rules

- `blocked`: required prior artifacts are missing, private-source rules fail, render sanity fails, route audit blocks, or export status blocks.
- `machine-review complete but manual review required`: rendered evidence and machine checks are present, route/export status is acceptable, and no manual approval is claimed.
- `ready for future promotion-review batch`: all machine gates pass and a future separate manual review may explicitly approve promotion.

Promotion remains outside this batch.
